# ADR-0002: TypeScript من طرف إلى طرف

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

فريق صغير يبني خادماً و3 عملاء ويحتاج مشاركة الأنواع والمنطق.

## القرار

TypeScript 5.9 على Node 22 في كل الحزم والتطبيقات، مع zod للتحقق وقت التشغيل.

## العواقب

- أنواع مشتركة وسرعة تطوير أعلى.
- أداء الـ CPU أقل من Go/Rust، ونتحمله لأن عنق الزجاجة هو النماذج والشبكة.
- `strict` و`noUncheckedIndexedAccess` إلزاميان.
