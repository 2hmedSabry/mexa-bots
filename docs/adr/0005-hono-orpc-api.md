# ADR-0005: Hono وoRPC للـ API

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

نحتاج عقوداً مُنمَّطة بين الخادم والعملاء الثلاثة، وOpenAPI للتكاملات الخارجية.

## القرار

Hono كإطار HTTP وoRPC للإجراءات مع مخططات zod في `packages/contracts`، وWebSocket للأحداث وSSE بديلاً.

## العواقب

- أنواع مولَّدة للعملاء وOpenAPI تلقائي.
- خفيف ويعمل على Node وBun والـ Edge.
- oRPC أحدث من tRPC وأصغر مجتمعاً، ونخفف ذلك بإبقاء العقود في zod العادي.
