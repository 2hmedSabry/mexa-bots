# ADR-0007: كمبيوترات Docker وتجريد المزوّد

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

كل منظمة تحتاج كمبيوتراً دائماً بمتصفح وشاشة، بنفس الصورة محلياً وسحابياً.

## القرار

صورة Docker (Ubuntu 24.04 مع Xvfb وnoVNC وChromium وagentd) خلف واجهة `ComputerProvider`. المزوّدون بالترتيب: `local-docker` ثم `docker-remote` ثم `e2b`/`daytona` ثم `fly-machines`. الشاشة: noVNC أولاً ثم WebRTC في المرحلة 4.

## العواقب

- نفس الصورة للتطوير والاستضافة الذاتية والسحابة.
- عزل Docker أضعف من VM، فنضيف seccomp وgVisor اختيارياً.
- noVNC أبسط لكن كمونه أعلى على الموبايل، فنؤجل WebRTC.
