# ADR-0008: Vercel AI SDK وموجّه النماذج مع Grok افتراضياً

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

نريد حرية اختيار النموذج لكل بوت، وسعراً مناسباً افتراضياً، وبثاً وأدوات بواجهة واحدة.

## القرار

Vercel AI SDK مع مزوّدي xAI (الافتراضي) وAnthropic وOpenAI وOpenRouter وOllama. Presets: `fast` و`balanced` (Grok 4.3) و`powerful` (Grok 4.5) و`custom`، مع fallback عند 429/5xx.

## العواقب

- تبديل المزوّد دون تغيير منطق الوكيل.
- الأسعار تتغير، فتُراجع جدول الأسعار قبل الإطلاق.
- BYO keys يحوّل تكلفة النماذج للمستخدم.
