# ADR-0006: PostgreSQL وPrisma وGraphile Worker

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

نحتاج بيانات علائقية وبحثاً متجهياً للذاكرة ووظائف مجدولة، مع تقليل المكوّنات للاستضافة الذاتية.

## القرار

PostgreSQL 16 مع pgvector، وPrisma 6 كـ ORM، وGraphile Worker للوظائف والـ cron داخل Postgres. Redis اختياري.

## العواقب

- مكوّن تخزين واحد يكفي للاستضافة الذاتية.
- Prisma لا يدعم vector أصلياً فنستخدم `Unsupported` وSQL خام للبحث.
- الوظائف تتشارك الاتصالات مع قاعدة البيانات فتلزم مراقبة الحمل.
