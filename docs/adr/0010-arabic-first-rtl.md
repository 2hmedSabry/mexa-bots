# ADR-0010: عربي أولاً مع RTL كامل

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

العربية سوق مستهدف رئيسي ولا يقدمها المنافسون بجودة.

## القرار

الواجهة بالعربية والإنجليزية من اليوم الأول: خصائص CSS المنطقية فقط، i18next، خطوط IBM Plex Sans Arabic وInter، أرقام وتواريخ عبر Intl، واختبارات لقطات بالاتجاهين.

## العواقب

- كل مكوّن يُختبر في RTL وLTR كجزء من تعريف الإنجاز.
- كلفة تطوير إضافية صغيرة مقابل تميّز واضح.
- محتوى الكود والطرفية يبقى LTR داخل حاوية RTL.
