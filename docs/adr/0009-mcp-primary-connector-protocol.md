# ADR-0009: MCP بروتوكول الموصلات الأساسي

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

نحتاج كتالوج تكاملات واسعاً دون كتابة كل موصل بأنفسنا.

## القرار

MCP (Streamable HTTP مع OAuth 2.1 وPKCE) هو الأساس، مع موصلات أولى بـ OAuth لأهم الخدمات. OpenAPI وComposio في v2. الاعتماد في خزنة AES-256-GCM.

## العواقب

- أي خادم MCP يمكن إضافته من المستخدم.
- جودة خوادم MCP متفاوتة، فنُصنّف خطورة الأدوات ونطلب موافقات.
- الموصلات الأولى تبقى للخدمات الحرجة.
