# ADR-0001: Monorepo بـ pnpm وTurborepo

- **الحالة:** مقبول
- **التاريخ:** 2026-10-04

## السياق

المشروع يضم API وworker وويب وديسكتوب وموبايل وحزمًا مشتركة، ويحتاج مشاركة العقود والأنواع بينها دون تكرار.

## القرار

مستودع واحد بـ pnpm workspaces وTurborepo وChangesets. الشجرة: `apps/*` و`packages/*` و`infra/` و`docs/`.

## العواقب

- تغيير عقد واحد يظهر فوراً في كل العملاء.
- يلزم كاش Turborepo ومراقبة حدود الاعتماد في CI.
- Expo وElectron يحتاجان إعداد hoisting خاصاً لكل تطبيق.
- بديل مرفوض: Nx (أثقل في الإعداد لفريقنا الصغير).
