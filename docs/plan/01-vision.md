# 01 — الرؤية والتموضع

الغرض: تحديد ما نبنيه ولمن، وما الذي يميّز Mexa Bots عن Grok Bot وRakazo.

## الفكرة

**Mexa Bots** منصة لإنشاء زملاء عمل بالذكاء الاصطناعي: بوتات دائمة لكلٍّ منها اسم ووظيفة وذاكرة، تعمل على كمبيوتر سحابي حقيقي (متصفح + طرفية + ملفات)، تنفّذ مهام فعلية داخل أدواتك وتستمر بعد إغلاق جهازك، وتتابعها من Android أو iPhone أو سطح المكتب أو الويب.

## المشكلة

1. المساعدون الحاليون يكتبون ولا ينفّذون؛ النتيجة مسودة تُنقل يدوياً.
2. لا ذاكرة ولا استمرارية بين المحادثات.
3. Grok Bot مقفل على مزوّد واحد، بلا اختيار نموذج، وبلا عربية/RTL.
4. Rakazo يتطلب تشغيلاً ذاتياً وتجربة موبايل محدودة.

## المقارنة

| البُعد | Grok Bot | Rakazo | Mexa Bots |
|---|---|---|---|
| المنصات | Desktop + iPhone/iPad/Android | Web + Electron + Expo | Web + Electron + Expo (Android وiOS بتكافؤ) |
| النموذج | ثابت | BYO | Grok افتراضياً + BYO |
| مكان التشغيل | سحابة Cursor | ذاتي أو sandbox | Cloud وSelf-hosted وDesktop Local |
| الكمبيوتر | VM واحد لكل مستخدم | Team + Private | Team أولاً، Private في المرحلة 4 |
| العربية/RTL | لا | لا | أولوية أولى |
| قنوات المراسلة | لا | لا | Telegram ثم WhatsApp وSlack |
| التسعير | ضمن اشتراكات Cursor/SuperGrok | مجاني | Free / Pro / Team / Self-hosted |

## ما نأخذه من المرجعين

**من Grok Bot (المنتج):**
- البوت: اسم + لقب + وصف مُهيكل (النتيجة، المصادر، الأدوات، شكل المخرج، ما يحتاج موافقة، ماذا يفعل عند نقص المعلومات).
- كمبيوتر مشترك لكل منظمة، لكل بوت شاشته، ولا حدود أمنية بين البوتات.
- Routines بجدول أو حدث، وسياسة إشعار تعتبر الصمت نتيجة صحيحة أحياناً.
- Skills تُحفظ ويُعاد تشغيلها. Takeover من الموبايل لكلمة المرور وMFA وCAPTCHA.
- الموبايل واجهة متابعة وتسليم سريع لا لوحة إدارة.
- تسلسل الوصول: موصل مُهيكل، ثم API/CLI رسمي، ثم المتصفح، ثم الجهاز المحلي.

**من Rakazo (التقنية):**
- بنية apps/packages/infra/docs، وHono + oRPC وPrisma وBetter Auth وGraphile Worker.
- تجريد مزوّد الكمبيوتر والموصلات (MCP وOpenAPI).
- Electron يشغّل كل شيء محلياً بصور Docker، وExpo كعميل API، وسكربت تثبيت يولّد `.env`.

## نقاط التميز

1. **عربي أولاً:** RTL كامل، خطوط عربية، أرقام وتواريخ محلية.
2. **Android + iOS + Desktop + Web من اليوم الأول** مع تكافؤ المشاهدة الحيّة والـ Takeover.
3. **حرية النموذج:** Grok افتراضياً وإمكانية التبديل لكل بوت.
4. **قنوات مراسلة:** خاطب بوتك من Telegram أو WhatsApp أو Slack.
5. **ثلاثة أنماط تشغيل:** Cloud، Self-hosted، Desktop Local.
6. **تسعير شفاف** بقياس الاستخدام وخطة مجانية حقيقية.

## الشخصيات المستهدفة

| الشخصية | الحاجة | مثال بوت |
|---|---|---|
| رائد أعمال/فريلانسر | بريد وفواتير وعملاء دون موظف | مساعد العمليات |
| مدير تسويق | رصد الأداء والمنافسين وتقارير أسبوعية | راصد المحتوى |

| شركة صغيرة في MENA | بيانات داخل الشركة وعربية | استضافة ذاتية + بوتات مبيعات/دعم |

## الخطط

| الخطة | السعر المبدئي | المحتوى |
|---|---|---|
| Free | 0 | بوت واحد، 10 ساعات كمبيوتر/شهر، Routines ×2 |
| Pro | ~20$/شهر | 10 بوتات، كمبيوتر دائم، 50 Routine/بوت، BYO keys، إملاء |
| Team | ~15$/مقعد | منظمات، كمبيوترات مشتركة وخاصة، أدوار، سجل تدقيق |
| Self-hosted | Community مجاني / Enterprise بترخيص | نفس الكود |

## مؤشرات النجاح (6 أشهر بعد الإطلاق)

- 1,000 مستخدم نشط أسبوعياً، 30% منهم لديهم Routine على الأقل.
- متوسط 3 بوتات لكل مستخدم مدفوع، ونجاح Runs دون تدخل فوق 80%.
- زمن أول رد على الموبايل أقل من ثانيتين، وتقييم المتجرين 4.5 فأكثر.
