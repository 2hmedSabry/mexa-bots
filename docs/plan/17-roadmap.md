# 17 — خارطة الطريق

الغرض: المراحل والتسليمات ومعايير الخروج. الإطلاق العام 1.0 عند نهاية المرحلة 4 (نحو 7 أشهر).

| المرحلة | الأسابيع | الاسم |
|---|---|---|
| 0 | 1–2 | الأساس |
| 1 | 3–8 | MVP: بوتات دائمة ومحادثة (🟢) |
| 2 | 9–16 | الكمبيوتر (🟡) |
| 3 | 17–22 | Routines والموصلات (🟡) |
| 4 | 23–30 | الفِرق والفوترة والقنوات والصوت وإطلاق المتاجر (🟡) |
| 5 | 31+ | التوسّع والمؤسسات (🔵) |

## المرحلة 0: الأساس (الأسبوعان 1–2)

- أدوات الـ monorepo وCI شغّال وPrettier/ESLint/Vitest.
- Prisma schema v1 وBetter Auth وdesign tokens وقشرة الويب.
- قشرتا Expo وElectron تعملان وتسجّلان الدخول.
- **معيار الخروج:** تسجيل دخول من الويب والديسكتوب وAndroid وiOS على بيئة dev، وCI أخضر.

## المرحلة 1: MVP (الأسابيع 3–8)

- إنشاء وتحرير البوتات، محادثة ببث، مرفقات.
- ذاكرة v1 (ملف شخصي وملخصات)، مزوّد Grok وmodel presets، موافقات المسودات، قياس الاستخدام.
- عربي/إنجليزي بـ RTL كامل، وديسكتوب يغلّف الويب بوضع Cloud.
- **معيار الخروج:** بيتا داخلية بـ 20 مستخدماً، TTFT أقل من ثانيتين، وزمن ردود مستقر.

## المرحلة 2: الكمبيوتر (الأسابيع 9–16)

- صورة الكمبيوتر وagentd ومزوّد `local-docker`.
- أدوات exec وfiles وbrowser وscreenshot وinput.
- شاشة حيّة بـ noVNC على الويب والديسكتوب والموبايل، وTakeover.
- بدء كسول وإيقاف عند الخمول، و`/workspace` دائم.
- compose للاستضافة الذاتية وسكربت التثبيت.
- **معيار الخروج:** بوت يُكمل مهمة متصفح من 10 خطوات، وTakeover ناجح على Android وiOS.

## المرحلة 3: Routines والموصلات (الأسابيع 17–22)

- Routines (cron وحدث، سياسة إشعار، آخر 20 تشغيلاً، Test run) وSkills v1.
- عميل MCP والموصلات الأولى (Google وNotion وSlack وGitHub) وخزنة الاعتماد.
- Push notifications، ومزوّد `docker-remote`، وذاكرة دلالية.
- **معيار الخروج:** Routine يومية تعمل 14 يوماً متتالية بنسبة نجاح فوق 95%.

## المرحلة 4: الفِرق والفوترة والإطلاق (الأسابيع 23–30)

- منظمات وأدوار، كمبيوترات مشتركة وخاصة، سجل تدقيق.
- Stripe وRevenueCat وحدود الاستخدام.
- قناة Telegram، إملاء STT، WebRTC للشاشة، ومزوّدا e2b وdaytona.
- إطلاق App Store وGoogle Play وإصدارات الديسكتوب، والموقع التسويقي.
- **معيار الخروج:** اجتياز مراجعة المتجرين، واختبار حِمل، ومراجعة أمنية.

## المرحلة 5: التوسّع (الأسبوع 31 فصاعداً)

Kubernetes وTerraform، `fly-machines`، SSO وSCIM، سياسة الشبكة وRoute egress، Local computer access، WhatsApp وSlack، صوت حي بـ LiveKit، OpenAPI import وComposio، متجر قوالب البوتات، والتحضير لـ SOC 2.

## المخاطر

| الخطر | الأثر | التخفيف |
|---|---|---|
| تغيّر أسعار/نماذج Grok | تكلفة | model router وBYO وfallback |
| رفض المتاجر (IAP، الذكاء التوليدي) | تأخير | RevenueCat مبكراً، مراجعة السياسات في المرحلة 1 |
| تكلفة الكمبيوترات | هامش | إيقاف عند الخمول وحدود الخطة ومراقبة يومية |
| Prompt injection | ثقة | موافقات وevals وallow-lists |
| تعقيد الشاشة الحيّة على الموبايل | جودة | noVNC أولاً ثم WebRTC، واختبار أجهزة حقيقية |
| فريق صغير | سرعة | حزم مشتركة ومنطق واحد للعملاء الثلاثة |
