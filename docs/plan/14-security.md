# 14 — الأمان والخصوصية

الغرض: نموذج التهديد والضوابط عبر المنتج.

## نموذج التهديد

| التهديد | الدفاع |
|---|---|
| Prompt injection من صفحات وملفات وبريد | محتوى غير موثوق، موافقات، allow-list للمجالات |
| تسرّب أسرار عبر النموذج | حقن التوكنات خارج النموذج، تقنيع، كاشف مفاتيح |
| هروب من الكمبيوتر | حاوية غير root وseccomp وبلا CAP_SYS_ADMIN وشبكة معزولة وgVisor اختياري |
| حركة جانبية بين المنظمات | كمبيوتر وvolumes ومفاتيح لكل منظمة، `organizationId` في كل استعلام، RLS لاحقاً |
| حساب مخترق | Passkeys وMFA، إنهاء الجلسات، تنبيه دخول جديد، قفل بيومتري |
| إساءة استخدام | حدود خطة وrate limiting وسياسة egress |
| سلسلة التوريد | lockfile، Dependabot، `pnpm audit`، صور موقّعة بـ cosign مع SBOM |

## المصادقة

- Better Auth: بريد (argon2id) وGoogle وApple وPasskeys وMagic link.
- كوكي HttpOnly وSameSite=Lax للويب، وتوكنات جهاز دوّارة للموبايل.
- TOTP اختياري للأفراد وقابل للإلزام للفِرق.
- PKCE وstate لكل تدفق موصل، وcallbacks على نطاق الـ API فقط.

## التفويض

أدوار المنظمة owner وadmin وmember. كل إجراء oRPC يمر بـ `authorize(ctx, resource, action)` مركزي مع اختبارات تغطي كل Router.

## حماية البيانات

- TLS 1.2+ وHSTS أثناء النقل، وأقراص مشفّرة وخزنة AES-GCM أثناء التخزين.
- Postgres بـ PITR يومي واختبار استعادة شهري.
- الاحتفاظ: لقطات الشاشة 30 يوماً، سجلات الوصول 90 يوماً، حذف صلب بعد 30 يوماً من حذف الحساب.
- تصدير البيانات من الإعدادات. إقامة البيانات في EU أو الشرق الأوسط للفِرق (🔵).

## الأمان التطبيقي

- CSP صارم، CSRF للكوكي، تحقق zod لكل مدخل، حدود حجم الرفع وفحص MIME.
- الأسرار في مدير أسرار لا في الصور.
- سجل تدقيق لكل فعل إداري وكل فعل خارجي للبوت.
- فحوصات CI: `pnpm audit` وSemgrep وgitleaks وTrivy.
- `SECURITY.md` لبرنامج الإفشاء المسؤول، وتدوير مفاتيح دوري.

## الامتثال

سياسة خصوصية وشروط بالعربية والإنجليزية، وجاهزية GDPR، ومتطلبات المتاجر. SOC 2 Type I مستهدف بعد 12 شهراً من الإطلاق للخطة الفريقية.
